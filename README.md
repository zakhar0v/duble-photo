# duble-photo

Программа для поиска дублей фотографий в указанной папке и всех вложенных папках.

## Технологии
- **Язык:** Python 3
- **GUI:** PyQt5
- **База данных:** SQLite

## Установка зависимостей

```bash
pip install PyQt5 Pillow
```

## Запуск

```bash
python duble_photo.py
```

## Возможности

1. **Сканирование папки** - рекурсивный обход указанной папки и всех вложенных
2. **Поддержка форматов** - JPG, JPEG, PNG, GIF, BMP, TIFF, TIF, WEBP
3. **Perceptual hashing** - умное сравнение изображений по визуальному сходству
4. **База данных SQLite** - сохранение результатов сканирования для последующего использования
5. **Поиск дублей** - группировка одинаковых изображений по хэшу
6. **Удаление файлов** - возможность удаления найденных дублей прямо из интерфейса
7. **Прогресс-бар** - отображение прогресса сканирования и поиска
8. **Логирование** - журнал всех операций

## Инструкция по использованию

1. Нажмите кнопку **"Выбрать папку"** и укажите директорию для сканирования
2. Нажмите **"Сканировать"** для анализа изображений
3. После завершения сканирования нажмите **"Найти дубли"**
4. Просмотрите результаты в таблице (дубли подсвечены серым)
5. Выделите ненужные файлы и нажмите **"Удалить выбранные"**

## Структура проекта

- `duble_photo.py` - основной файл программы
- `image_hashes.db` - база данных хэшей (создается автоматически в выбранной папке)
